# NERO Agency

Web design à medida para negócios em Portugal.

## Sobre

Landing page profissional com animações premium, smooth scroll e design minimalista. Desenvolvida com GSAP, Lenis e HTML/CSS puro.

## Começar

```bash
# Instalar dependências
npm install

# Correr localmente
npm run dev
```

Abre `http://localhost:8080` no browser.

## Estrutura

```
public/
├── index.html          # Página principal
└── images/             # Imagens e assets
src/                    # (Para desenvolvimento futuro)
```

## Stack

- HTML5, CSS3, JavaScript
- GSAP & ScrollTrigger (animações)
- Lenis (smooth scroll)
- Sem frameworks, sem build tools

## Performance

- Lazy loading em imagens
- GPU-friendly animations
- Suporte a `prefers-reduced-motion`
- Mobile-first responsive

## Deploy

Hospedado no [Render](https://render.com). Push para `main` e faz deploy automático.
